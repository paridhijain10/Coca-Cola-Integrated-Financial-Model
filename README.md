# Coca-Cola Integrated Financial Model

An integrated 3-statement financial model and DCF valuation of The Coca-Cola Company (NYSE: KO).

## Project Overview

Built an integrated financial model using Coca-Cola's historical financials from 2022–2025 to forecast financial performance through 2030.

The model links operating assumptions with the Income Statement, Balance Sheet, Cash Flow Statement, and supporting schedules to produce an FCFF-based DCF valuation.

## Model Structure

- Historical Financials (2022–2025)
- Operating Assumptions
- Income Statement Forecast (2026–2030)
- Balance Sheet Forecast
- Cash Flow Forecast
- Working Capital Schedule
- PP&E Schedule
- Debt Schedule
- DCF Valuation
- WACC–Terminal Growth Sensitivity Analysis
- Valuation Dashboard

## Valuation Methodology

The DCF uses:

- Free Cash Flow to Firm (FCFF)
- Weighted Average Cost of Capital (WACC)
- Gordon Growth Model for terminal value

### Base Case

| Assumption | Value |
|---|---:|
| WACC | 7.0% |
| Terminal Growth Rate | 2.5% |

## Key Outputs

- Enterprise Value: ~$251.2B
- Equity Value: ~$215.9B
- Implied Share Price: $50.07
- Sensitivity Range: $36.23–$77.69
- Revenue CAGR (2025–2030): 4.0%
